# Contributing

Use this repository's issue tracker to report a bug or request a sample. Pull requests are not
accepted yet. A maintainer will use the issue to discuss scope, ownership, and delivery.

## Sample README template

Every sample README uses these level-two headings in this order. Keep the headings unchanged so
readers can find the same information in every sample.

```markdown
## What this shows

## Prerequisites

## Assets

## Files and APIs

## Run it

## What to expect

## Inspecting results

## Troubleshooting

## Extending it

## Assets, licensing, attribution
```
