# Security policy

Report suspected security vulnerabilities through this repository's private reporting form, under
the Security tab, using "Report a vulnerability". That channel is private between you and the
maintainers, and it is the only one we monitor for this purpose.

Include a clear description, reproduction steps, affected versions, and any proof of impact. Do not
open a public issue for a suspected vulnerability, because issues here are visible to everyone.

We will acknowledge the report, assess it, and coordinate a response in that private thread.
